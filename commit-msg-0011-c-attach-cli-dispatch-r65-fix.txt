- POSIX 0o600 regression security-gate (HIGH): replace
  let _ = f.set_permissions(...) with if let Err(io) =
  f.set_permissions(...) then return OctoCliError::Internal
  with sanitized IO error in the message body. chmod
  failure on a credential file is a HIGH-severity security
  finding (the very credential-leak window the fix was
  supposed to close), not a soft warning. Update rationale
  comment to remove the non-fatal claim. The surrounding
  file-mutation block (create_dir_all, open, write, fsync)
  all propagate IO errors already, so this aligns the
  chmod call to the same discipline.

  file:line ref 'identity.rs:204' from the doc-block
  (HARD per [[no-line-refs-anywhere]] — prose must use

  16-line doc-comment to a compact 7-line rationale
  covering only the substrate-faithful contract.

  OctoCliError::AlreadyRotating arm (exit 3) above the
  other wildcard. Substrate IdentityKey::activate returns
  RotationInProgress for LifecycleState::Rotating, the
  existing AlreadyRevoked to OctoCliError::AlreadyRevoked

  Rotating deserves the symmetric mapping per the R5.5
