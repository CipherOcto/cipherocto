## Backlog (RFC-0968 AC items NOT landed)

This backlog is the next mission-worthy work. Recommended
decomposition:

1. **0968-d-error-enum-rename-and-extend** — wholesale renumber
   of `ReputationError` from 22 to 57 variants per AC line 48,
   with all consumer crates updated. Cross-cutting.
2. **0968-d-recorder-lifecycle** — `RecorderState` 7-variant
   enum + transitions + escalation N=2..=10 + per-recorder
   severity counter (`severity_emitted_total`) + per-subject
   admission gates including `SelfDealingEvidence = 0x31`.
3. **0968-d-tombstoned-replay** — `RotationProvenanceMissing =
0x39` test plus `ReplayRecord.rotation_provenance` wire field
   - `consume_rotation_receipt` flow with rotation tuple locks.
4. **0968-d-clock-boundary** — `pub trait Clock { fn now_unix()
-> u64 }` at the RPC boundary + remove caller-supplied
   `now_unix` args from public RPCs (trusted-clock API per
   amendment 27).
5. **0968-d-auth-types** — `RecorderRegistrationRequest`,
   `ReaderAuth`, `AuditorAuth`, `RetentionAuth`,
   `GovernanceRegistry`, `GovernanceError` + `RETENTION_ROLE`
   bitfield.
6. **0968-d-normalizer** — `Normalizer` trait + `NormalizerInput`
   - `MAX_SEVERITY` + drift-second constants.
7. **0968-d-cargo-features** — add `mon`, `dc`, `marketplace`,
   `wallet` feature flags to `octo-reputation/Cargo.toml`.
8. **0968-d-provider-compat** — `ProviderReputationRegistryCompat`
   per mission `open/0968-b` Phase A.
9. **0968-d-presentation** — `reputation_score_0_100` with
   `Result<u8, ReputationError>` + 101-unique-values test per
   mission `open/0968-b` Phase C.
10. **0968-d-cli** — `quota-router reputation show --did <did>`
    per mission `open/0968-b` Phase E.

Items 1-3 are infrastructure (any consumer of `ReputationError`
must update). Items 4-7 are additive (no renumbering).
Items 8-10 are downstream of the `open/0968-b` mission and
cross-reference that plan.
