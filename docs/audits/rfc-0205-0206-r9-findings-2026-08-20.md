### Trigger 1: Substrate newtype refactor cannot close C4/C5 TYPE leak (CODE CHANGE REQUIRED)

- `octo-storage-core::open()` / `open_in_memory()` return `Result<stoolap::Database, _>` — the bare fork type leaks to Layer B signatures
- 26+ sites in `crates/quota-router-storage/src/{ask_repo.rs, slash_store.rs, migrations.rs, stoolap_did_registry.rs, stoolap_spend_ledger.rs, settlement_event_repo.rs}` use `stoolap::Database` as TYPE

- Fix requires code change: `pub struct Database(stoolap::Database);` + Layer B TYPE renames
- Reviewers: substrate-leak-deep-read (F1 CRIT + F3 CRIT), substrate-newtype-reviewer (CRIT 3 + CRIT 4), substrate-pub-use-count-drift (F6 MED cross-RFC schedule drift)

### Trigger 2: SHA-256 git migration requires full repo init — tag `--object-format=sha256` flag is fabricated

- RFC claims `git tag -s <tag> --object-format=sha256` defends against tree-hash collision
- Per `git-tag(1)` manual: `--object-format` is documented only for `git init` and `git clone`; tags inherit repository object format from `extensions.objectFormat`
- Tag dereferences to SHA-1 commit → SHA-1 tree; SHA-256 tag wrapper provides zero protection against tree-hash collision
- Fix requires full repo re-init: `git init/clone --object-format=sha256` + bidirectional hash translation table
- Reviewers: shattered-cost-reviewer (F2 CRIT), TV-implementation-correctness (F1 CRIT)

### Trigger 3: ykman command fabrication + URL 404

- §HW Key Custody §Firmware Attestation (line 97) cites `ykman attestation verify`
- `ykman` top-level command tree has no `attestation` subcommand and no `verify` action
- Correct invocation: `ykman fido attest` → PEM cert → `openssl verify` against pinned root
- Cited URL `https://developers.yubico.com/PKI/Attestation/` returns HTTP 404 as of 2026-08-20
- Yubico migrated to `docs.yubico.com`; canonical attestation per-applet (PIV vs FIDO2)
- Fix requires §HW Key Custody wholesale rewrite + new script `scripts/ykman-attest-verify.sh` + vendored Yubico root cert
- Reviewers: FIDO2-firmware-CVE-reviewer (F1 CRIT + F6 HIGH), TV-implementation-correctness (F4 CRIT)
