```mermaid
  DEV_SDK --> NODETYPE[NodeType: Wholesale, SelfHost, Hybrid]
```

## 3. Five Invariants (the rules we never break)

1. **Sovereign identity** — node DID ≠ provider's identity. Provider keys live only in octo-wallet vault.
2. **Capability over identity** — every authorization grant is a macaroon; no global identity lookup needed at verify time.
3. **Provider opaque** — capability tokens never cross provider boundary; egress transform is single egress point.
4. **Pairwise unlinkability** — every relationship has independent capability material; attenuation only narrows.
5. **OCTO-W native** — protocol math denominated in OCTO-W; fiat ramps live one layer up (RFC-0955 = Model Liquidity Layer Draft, which covers fiat ramp side). Note: settlement has TWO independent chains: RFC-0909 (Accepted v69, virtual-API-key spend tracking via SHA-256 over SpendEvent) + RFC-0959 (Draft 2026-07-20, **independent settlement chain** per Option A; promotion to Accepted pending 7-day review per BLUEPRINT). Coexistence, no amendment relationship.
