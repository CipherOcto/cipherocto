# Mission `0206-011-rfc-0206-v21-amendment` v1.0 — OPEN 2026-08-20 → DONE 2026-08-22

## Scope

RFC-0206 → v2.1 amendment. RFC-only (no code). Resolves 4 CRIT blockers identified in R3 aggregation (`docs/audits/missions-r3-findings-2026-08-20.md`):

1. **CRIT-1: pub-use cap contradiction** — §Cargo.toml Templates Layer A lines 99-111 shows 11 top-level `pub use` statements; §Substrate Newtype Refactor line 244 imposes ≤ 8 cap with "MOVE 3 to module attrs `pub mod migrations`" guidance. RFC v2.0 spec is internally inconsistent.

2. **CRIT-2: §Layer B TYPE Renames table incomplete** — v2.0 table (lines 191-216) covers 29 sites across 2 crates (`quota-router-storage` + `octo-vault`). On-disk `docs/audits/octo-storage-trait-surface-2026-08-19.md` documents 13 crates with direct stoolap deps (octo-reputation, octo-matrix-session-store, octo-cap-macaroon-vault, octo-adapter-whatsapp, octo-adapter-telegram-mtproto, quota-router-core, quota-router-sm-engine, quota-router-cli, octo-whatsapp, etc.) using `stoolap::Database` directly. v2.0 table underspecifies scope by ~3x.

3. **CRIT-3: Owner-trait method signatures undefined** — §Wiring Pattern lines 150-171 shows comment-only stub `pub trait VaultStore { /* declared in owner crate octo-vault, impl'd here */ }` with `todo!()` bodies. `ReputationStore`, `SessionStore`, `PolicyStore` traits also lack method signatures. 0206-009 cannot implement adapters without concrete trait shapes.

4. **CRIT-4: §RFC Process Audit Condition 2 wording** — line 440 says "substrate newtype + 29 TYPE renames + 5 adapter crates". With CRIT-2 expansion, Condition 2 wording must reflect actual scope.

Plus 2 scope improvements:

5. **HIGH-1: §Migration Order section missing** — v2.0 substrate redesign breaks current `apply_pending` / `Migration` trait / `open` / `open_in_memory` free function API (existing API per `crates/octo-storage-core/src/lib.rs` lines 46-52). Transition plan needed: legacy API coexistence strategy.

6. **HIGH-2: §From<Database> escape hatch enumeration** — v2.0 line 216 mentions "Layer A handle escapes ONLY at adapter-impl sites that already use typed queries from allowlist" but no enumerated legitimate-site list. 0206-002 v3.0 AC gate needs enumeration to subtract from rename count.
