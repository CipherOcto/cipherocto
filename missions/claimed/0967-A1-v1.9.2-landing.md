# Mission `0967-A1-v1.9.2-landing` v1.0 — OPEN 2026-08-24

## Context

RFC-0967-A1 v1.9.2 (canonical Accepted 2026-08-24 per `rfcs/accepted/economics/0967-a1-policy-registry.md` YAML frontmatter + amendment file `0967-a1-a1-workflowkind-trait-sig-amendment.md` v1.2 effective 2026-08-22) extends RFC-0967 v1.1-Resolved parent with:

- 6 policy-kind traits (AuthorityPolicy, MembershipPolicy, InteropPolicy, BurnPolicy, WorkflowKind, AuditPolicy) — per §v1.7 row "6-trait surface"
- `kind_uuid_registry` — 30 per-policy-kind UUIDv5 fixtures per §2.6 table (6 Auth + 7 Membership + 4 Interop + 3 Burn + 4 Workflow + 3 Audit + 3 Selector)
- `domain_separators` — canonical `octo/` prefix migration per F-R8-DOMSEP-PREFIX-DRIFT
- `WorkflowKind` trait signature amendments per F-R8-WFCOMPOSITE-NO-PROOF-PARAM (4 methods take `proof: &[u8]` parameter)
- `PolicyRegistry` trait extension per RFC-0967-A1 §PolicyRegistry (adapter crate substrate)

Per v1.9.2 VH row 1.5: all new substrate is "RFC-defined extension pending substrate landing via 0206-001 v3.0 + 0206-009". Mission `0967-a-policy-object-graph` (LANDED 2026-08-07) implements RFC-0967 v1.0 PolicyObject + intersect + is_subgraph only; v1.9.2 additions not yet landed in `crates/octo-policy/src/` or `crates/octo-policy-storage/src/` per audit 2026-08-24.
